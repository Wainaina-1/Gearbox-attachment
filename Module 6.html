Sensors

- For this week's work I looked at sensors and their various applications and from my research this what I learn;

Definition- A sensor is a device that detects changes in its environment—such as light, temperature, pressure, motion, or chemical composition—and converts those changes into measurable electrical signals.
How sensors are classified:

By power requirement:

  • Active: Require external power to operate.
  • Passive: Generate signals directly from the stimulus, without external power.

    • By output type:
  • Analog: Provide continuous signals (e.g., varying voltage, current, or resistance).
  • Digital: Output discrete values, like binary data for microcontrollers.

    • By sensing method or property:
  • Temperature (e.g., thermocouples, RTDs, thermistors)
  • Pressure (e.g., piezoelectric, capacitive, strain gauge)
  • Light/Optical (e.g., photodiodes, photoelectric sensors)
  • Proximity/Motion (e.g., inductive, capacitive, ultrasonic, PIR)
  • Chemical/Gas (e.g., gas detectors, biosensors)
  • Position/Angle (e.g., encoders, accelerometers, gyroscopes)
  • Force/Weight (e.g., strain gauges, load cells)
  • Color, Humidity, pH, Tilt, Sound, Touch, Radiation, Magnetic etc.

    • Notable specialized types:
  • Proximity sensors: Detect objects without contact, used in smartphones and industrial settings.
  • Occupancy sensors (PIR, ultrasonic, microwave): Detect human presence to control lights or HVAC systems.
  • Electro-optical sensors: Convert light into electrical signals for applications like automatic lighting or object detection.

    • Common applications:
  • IoT & Smart Environments: Home automation, agriculture, smart cities.
  • Industrial & Automotive: Process control, safety systems, engine monitoring.
  • Wearables & Healthcare: Monitoring vital signs and bodily functions.
  • Environmental: Tracking air quality, water levels, pollution.
  • Consumer Electronics: Features like auto‑rotate screens, touch interfaces, ambient light sensing.

    -For this project I was using a PIR motion sensor which was meant to detect motion and in turn an LED would turn on if there was any motion detected.
    Procedure:

  • I first came up with the code required for the above project and wrote it down on Arduino IDE.
  • I then connected the ESP32 to a breadboard using the provided wires and placed all the other required components on the breadboard connecting them accordingly.
  • After cross checking my connections I uploaded and ran my code to see if the PIR sensor was detecting motion.

    • Code used:

    int sensor = 18; // Set pins for PIR
    int led = 23; // Set pin for LED
    void setup() {
    Serial.begin(115200); // initialize serial monitor
    pinMode(sensor, INPUT); // set PIR as input
    pinMode(led, OUTPUT); // set LED as output
    }
    void loop() {
    long state = digitalRead(sensor); // read PIR state
    if (state == HIGH) {
    digitalWrite(led, HIGH);
    Serial.println("Motion detected");
    delay(100);
    } else {
    digitalWrite(led, LOW);
    Serial.println("No motion detected!");
    delay(100);
    }
    }

    Project 2- Measuring distance using an ultrasonic sensor.

    -For this project I used an ultrasonic sensor to measure the distance between an obstacle and the ultrasonic sensor itself.
    Procedure:

  • I first came up with the code required for the above project and wrote it down on Thonny
  • I then connected the Raspberry pi pico to a breadboard using the provided wires and placed all the other required components on the breadboard connecting them accordingly.
  • After cross checking my connections I uploaded and ran my code to see if the ultrasonic sensor was measuring the distance.

    • NB: A voltage divider is required to avoid damaging the pins of the raspberry pi since the ultasonic sensor's output is 5V and the pins can only safely accomodate 3.3V.

    Code used:

    from machine import Pin, time_pulse_us
    import utime

    TRIG_PIN = 3
    ECHO_PIN = 2

    SOUND_SPEED = 343.2 # m/s at ~20°C
    TIMEOUT_US = 30000 # 30 ms -> ~5 m max

    trig = Pin(TRIG_PIN, Pin.OUT, value=0)
    echo = Pin(ECHO_PIN, Pin.IN)

    def measure_distance_cm(samples: int = 5):
    """Return the median of N samples in cm (or None if all failed)."""
    readings = []
    for _ in range(samples):
    # Trigger a 10 µs pulse
    trig.value(0)
    utime.sleep_us(2)
    trig.value(1)
    utime.sleep_us(10)
    trig.value(0)

    # Measure echo high pulse
    duration = time_pulse_us(echo, 1, TIMEOUT_US)
    if duration > 0: # valid reading
    distance_cm = (duration / 1_000_000) * (SOUND_SPEED / 2) * 100.0
    readings.append(distance_cm)

    utime.sleep_ms(50)

    if not readings:
    return None
    readings.sort()
    return readings[len(readings)//2] # median

    def main():
    try:
    while True:
    d = measure_distance_cm()
    if d is None:
    print("Out of range / timeout")
    else:
    print("Distance: {:.2f} cm".format(d))
    utime.sleep_ms(200)
    except KeyboardInterrupt:
    print("\nStopped.")

    if __name__ == "__main__":
    main()
