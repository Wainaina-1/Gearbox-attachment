Introduction to embedded systems

This module mainly focuses on common electronic components used in embedded systems.

Theory

Definitions:
-An Electronic circuit is a complete circular path that electricity flows through. It directs and controls electric current to perform various functions.
-Electrical components- These are elements of an electronic circuit that perform specific functions tht are in line wit the flow of electric current.
-Some of the electrical components used are: resistors, LEDs and wires.

Projects done;

-The following are the projects I carried out:
  • Blinking of both the ESP's internal LED and an external LED
  • Fading of an LED

    • -For the projects carried out I implemented the use of the following components and apparatus:
  • LEDs
  • Wires
  • 220 ohm Resistors
  • ESP 32
  • Breadboard
  • A power source

    • PROJECT 1- Blinking of the ESP's internal LED.
    -For this first project all that was required was an ESP 32 and the blinking code found on Arduino IDE.
    -After uploading the code to the ESP 32 I was able to see the ESP's internal LED blink.
    Below is the code I used for the above project;
    void setup() { // initialize digital pin LED_BUILTIN as an output. pinMode(LED_BUILTIN, OUTPUT); } // the loop function runs over and over again forever void loop() { digitalWrite(LED_BUILTIN, HIGH); // turn the LED on (HIGH is the voltage level) delay(1000); // wait for a second digitalWrite(LED_BUILTIN, LOW); // turn the LED off by making the voltage LOW delay(1000); // wait for a second }
