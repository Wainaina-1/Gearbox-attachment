    Project 3- Fading of an external LED
    -For this project I fading an external LED using an ESP32 and Arduino IDE to write down the code required.
    Procedure:

  • I first came up with the code required for the above project and wrote it down on Arduino IDE.
  • I then connected the ESP32 to a breadboard using the provied wires and placed all the other required components on the breadboard connecting them accordingly.
  • After cross checking my connections I uploaded and ran my code to see if the LED would fade.

    • Results;
    -The LED increased in brightness and then gradually faded.
    Below is a video showing my results and the code I implemented;

    -Code used:

    ledPin = 5;

    setup() {
    pinMode(ledPin, OUTPUT);
    }

    loop() {
    for (brightness = 0; brightness <= 255; brightness++) {
    analogFade(ledPin, brightness);
    }

    for (brightness = 255; brightness >= 0; brightness--) {
    analogFade(ledPin, brightness);
    }
    }

    analogFade(pin, brightness) {
    onTime = map(brightness, 0, 255, 0, 1000);
    cycleTime = 1000;

    for (i = 0; i < 5; i++) {
    digitalWrite(pin, HIGH);
    delayMicroseconds(onTime);
    digitalWrite(pin, LOW);
    delayMicroseconds(cycleTime - onTime);
    }
