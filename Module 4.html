Projects done:

Project 1- Blinling of the onboard LED.
-For this project all that was required was a raspberry pi pico and a blinking code.
-Code used:

from machine import Pin
from time import sleep
led = Pin(25, Pin.OUT)
while True:
led.toggle() # Turns LED on/off
sleep(1) # Wait for 1 second

Results; -The onboard LED blinked at intervals of 1 second.
